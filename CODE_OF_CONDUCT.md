# Code of Conduct

Strix is built in the open for anyone researching Robinhood Chain. We want this to be a welcoming,
harassment-free place for everyone, regardless of background or experience.

## Expected behaviour

- Be respectful and constructive in issues, pull requests and discussions.
- Assume good intent; critique ideas and code, not people.
- Back claims about tokens or wallets with data — no shilling, no FUD.

## Not acceptable

- Harassment, insults, discrimination or personal attacks.
- Promoting tokens, scams or paid services, or posting someone's private information.
- Using Strix issues to accuse projects without evidence.

## Enforcement

Maintainers may edit or remove comments, close issues and block accounts that break this code.
Report problems privately through
[GitHub's private reporting](https://github.com/strixagents/Strix/security/advisories/new) or by
contacting the maintainers on X ([@strix_agents](https://x.com/strix_agents)).

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org).
